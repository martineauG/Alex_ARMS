## eDNAFlow 
Contains parameters used as well as raw abundance tables and fasta files of sequences processed with the [eDNA Flow pipeline](https://github.com/mahsa-mousavi/eDNAFlow) (Mousavi‐Derazmahalleh et *al.*, 2021). 

## Blastn
Contains custom BLASTn sponge data base, commands/parameters and outputs from both BLASTn searches against 1) sponge curated data base and 2) entire GenBank nt data base. 

## R_clean_tables
Contains custom R script performing merging of two sequencing runs outputs, sample rarefaction,  filtering of BLASTn resulst, merging of BLASTn outputs from two different data bases and taxonomic assignment of ZOTUs. Final abundance, taxonomy tables and meta data can be found in this folder.
