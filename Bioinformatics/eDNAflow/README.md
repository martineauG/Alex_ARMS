- zotu_table_names_modified.csv: raw abundance matrix in csv format with corrected samples name (output from [Martineau_AlexARMS_bioinformatics_cleantable_bothseqruns.R](https://github.com/martineauG/Alex_ARMS/blob/main/Bioinformatics/R_clean_tables/ZoTU_Taxonomy/scripts/Martineau_AlexARMS_bioinformatics_cleantable_bothseqruns.R).
